VR GAME

Proyecto de Realidad Virtual

Este proyecto consiste en el desarrollo de un videojuego en realidad virtual utilizando herramientas web y GitHub para el trabajo colaborativo. El objetivo es crear una experiencia interactiva y dinámica para los usuarios.
